# The 2123 Project

A visionary web application celebrating Trinity College's Bicentennial by imagining the world 100 years from now. This interactive platform showcases AI-generated trading cards, community-driven futuristic visions, and explores the innovations, culture, and possibilities of the future.

## 🌟 Overview

The 2123 Project is an innovative initiative that combines historical celebration with forward-thinking vision. Using AI-generated trading cards, historical archives, and community-driven ideas, we explore what life might look like in 2123 - Trinity College's Tercentennial year.

## ✨ Features

### 🎨 Interactive Design

- **Responsive Layout**: Fully responsive design that works seamlessly across desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, contemporary interface with smooth animations and micro-interactions
- **Accessibility**: WCAG compliant with screen reader support, keyboard navigation, and proper ARIA labels

### 🌓 Theme System

- **Light/Dark Mode Toggle**: Switch between light and dark themes with complete color inversion
- **Trinity Branding**: Maintains Trinity College's blue and gold color scheme
- **Smooth Transitions**: All theme changes animate smoothly for a polished experience

### 🎠 Interactive Carousel

- **Featured Works Gallery**: Showcase AI-generated vision cards in an interactive carousel
- **Navigation Controls**: Previous/Next buttons and dot indicators for easy navigation
- **Auto-play**: Automatic slideshow with pause-on-hover functionality
- **Keyboard Support**: Navigate with arrow keys for accessibility

### 📝 Vision Submission

- **Create Your Own**: Users can submit their own futuristic visions
- **Form Validation**: Real-time validation with helpful error messages
- **Success Feedback**: Modal confirmation with animated celebration

### 🧭 Navigation

- **Smooth Scrolling**: Seamless navigation between sections
- **Sticky Header**: Navigation bar stays visible while scrolling
- **Scroll-to-Top**: Convenient button to return to the top of the page

## 🏗️ Technical Stack

## 🚀 Getting Started

1. **Open the Website**: Simply open `index.html` in any modern web browser
2. **Explore**: Use the navigation menu or scroll through sections
3. **Submit a Vision**: Click "Create Your Own" to share your futuristic idea
4. **Toggle Themes**: Use the theme toggle button to switch between light and dark modes
5. **Navigate**: Use the carousel controls to browse featured works
